## 🎯 WHAT IS URBAN HELPERS?

Urban Helpers is a **mobile app** that combines:
- **Health tracking** (steps, sleep, calories, fitness)
- **Home services** (cleaning, pest control, pet care, delivery)

All in **ONE app**. No more switching between multiple apps.
