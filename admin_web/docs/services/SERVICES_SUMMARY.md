## OTP Verification Feature

**Purpose:** Customer verifies the vendor's identity before allowing service to start.

### How It Works
1. Vendor arrives → vendor's app shows a **4-digit OTP**
2. Customer taps **"Verify & Start Service"** on `YourHelperHasArrived`
3. Customer enters the 4 digits shown on vendor's screen
4. App validates OTP → proceeds to `HelperVerified` on success

### OTP Specs
| Property | Value |
|---|---|
| Length | 4 digits |
| Expiry | 3 minutes (180 seconds) |
| Timer display | `MM:SS` countdown on screen |
| Wrong OTP | Red border + error message, input cleared |
| Resend | Customer can request a new code |
| Max attempts | 5 (then lockout) |
| Delivery method | Shown on vendor's app — no SMS needed |

### OTP Screen Features
- Auto-advance: cursor moves to next box after each digit
- Backspace: cursor moves back to previous box
- Disabled verify button until all 4 digits entered
- Error state: red input borders + message below boxes
- Safety card: "Only start after confirming helper's identity"

## Service Recording Feature

**Purpose:** Optional audio+video recording of the service session for safety, quality assurance, and dispute resolution.

### Recording Flow
```
ServiceRecordingConsent
    ├── [Start Recording] → RecordingInProgress
    │       ├── [Pause]   → RecordingPaused
    │       │       └── [Resume] → RecordingInProgress
    │       └── [End]     → EndServiceRecording → ServiceCompleted
    │
    └── [Skip Recording]  → RecordingInProgress (no recording)
                                  └── [End] → ServiceCompleted
```

### Recording Screen Features

**ServiceRecordingConsentScreen**
- Hero illustration
- Benefits: Service verification · Safety · Dispute resolution · Quality review
- Privacy warning: "Both parties must be informed"
- Consent checkbox (must tick to enable Start Recording)
- Two options: Start Recording / Continue Without Recording
- Privacy Policy link

**RecordingInProgressScreen**
- Pulsing red dot + `RECORDING` label
- Live timer: `HH:MM:SS` counting up every second
- Vendor name + service shown
- Animated concentric ring visual with camera icon
- Privacy notice: "Protected under Urban Helpers Privacy Policy"
- **Pause Recording** button
- **End Service** button (red gradient)

**RecordingPausedScreen**
- Amber pause icon
- Shows total time recorded so far
- **Resume Recording** (amber gradient) → back to live recording
- **End Service** → end confirmation

**EndServiceRecordingScreen**
- Red stop icon
- Shows recording duration
- Two choices: Continue Recording / Confirm End Service

### Recording Specs
| Property | Value |
|---|---|
| Type | Audio + Video |
| Consent required | Yes — both customer and vendor |
| Storage | Cloud (configurable bucket) |
| Retention period | 30 days |
| Access | Customer · Vendor · Admin |
| Format | MP4 |
| Max quality | 720p |
| Playback | Available in ServiceSummary screen |
| Report issue | Button on ServiceCompleted + ServiceSummary |
