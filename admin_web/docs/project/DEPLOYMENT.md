# Deployment Guide — Urban Helpers\n\n> Complete guide to deploy Urban Helpers to Google Play Store, App Store, and production environments.\n\n---\n\n## 📋 Pre-Deployment Checklist\n\n- [ ] All tests passing\n- [ ] TypeScript compilation clean\n- [ ] Version bumped (in `app.json`)\n- [ ] Release notes prepared\n- [ ] Privacy policy & terms updated\n- [ ] Screenshots & store listing prepared\n- [ ] Signing keys backed up\n- [ ] TestFlight/beta testers invited\n\n---\n\n## 🚀 Quick Start: GitHub Actions Build\n\nThe easiest way to build:\n\n1. Push to GitHub repository\n2. GitHub Actions automatically triggers\n3. APK builds in ~10 minutes\n4. Download from **Actions → Artifacts**\n\n**Status:** [GitHub Actions Builds](https://github.com/designingoff-pixel/UrbanHelpersApp/actions)\n\n---\n\n## 📱 Android Deployment\n\n### Option 1: GitHub Actions (Recommended)\n\nAlready configured in `.github/workflows/build-apk.yml`\n\n**No additional setup needed** — Just push to main!\n\n### Option 2: Local Build\n\n#### Prerequisites\n```bash\n# Install Expo CLI\nnpm install -g eas-cli\n\n# Login to Expo account\neas login\n```\n\n#### Build Debug APK\n\n```bash\n# Build locally\nnpx expo build:android --platform android --type apk\n\n# Or with clean build\nnpx expo build:android --platform android --type apk --clear\n```\n\n**Output:** APK file (~45 MB)\n\n#### Build Release APK (for Play Store)\n\n```bash\n# Build signed APK\nnpx eas build --platform android --type app-signing\n\n# This will:\n# 1. Ask for signing config (or create new)\n# 2. Build optimized APK\n# 3. Sign for Play Store\n# 4. Upload to EAS servers\n```\n\n**Time:** ~15 minutes\n\n#### Build via Expo CLI (Alternative)\n\n```bash\ncd UrbanHelperApp/UrbanHelpersApp/UrbanHelpersApp\n\n# Prebuild Android project\nnpx expo prebuild --platform android --clean\n\n# Build APK\ncd android\n./gradlew assembleRelease\n\n# Signed APK location:\n# ./app/build/outputs/apk/release/\n```\n\n### Deploy to Google Play Store\n\n#### 1. Setup Google Play Console\n\n```bash\n# Go to https://play.google.com/console\n# Create app → Urban Helpers\n# Accept policies & agreements\n# Setup payment info\n```\n\n#### 2. Prepare Store Listing\n\n```\nApp Details\n├── App name: Urban Helpers\n├── Short description: \"One App. Better Health. Better Home. Better Living.\"\n├── Full description: [See EXECUTIVE_PRESENTATION.md]\n├── Screenshots: [4-5 screenshots from design files]\n├── Icon: [512x512 PNG]\n├── Feature Graphic: [1024x500 PNG]\n└── Privacy Policy: [Link to privacy policy]\n\nTargeting\n├── Minimum API: 29 (Android 10)\n├── Target API: Latest\n├── Permissions: [Already declared in app.json]\n└── Content Rating: General Audience\n```\n\n#### 3. Upload APK\n\n```bash\n# Option A: Upload via Console (manual)\n1. Google Play Console → Your App\n2. Release → Production\n3. Upload APK\n4. Review and publish\n\n# Option B: Upload via CLI (automated)\nnpx eas submit --platform android --latest\n```\n\n#### 4. Review & Publish\n\n- [ ] Review store listing\n- [ ] Check screenshots\n- [ ] Verify app permissions\n- [ ] Test on multiple devices\n- [ ] Submit for review\n- [ ] Wait for Google approval (~3-4 hours)\n- [ ] Schedule release or publish immediately\n\n**Success:** App appears on Play Store in ~2-4 hours\n\n---\n\n## 🍎 iOS Deployment (App Store)\n\n### Prerequisites\n\n- Apple Developer Account ($99/year)\n- Mac with Xcode\n- iOS provisioning profiles\n- App certificates\n\n### Build for TestFlight\n\n```bash\n# Create Apple Team ID\n# Go to App Store Connect → Membership → Team ID\n\n# Update app.json with iOS config\n{\n  \"ios\": {\n    \"bundleIdentifier\": \"com.urbanhelpers.app\",\n    \"buildNumber\": \"1\",\n    \"supportsTablet\": true,\n    \"requireFullScreen\": true,\n    \"infoPlist\": {\n      \"NSLocationWhenInUseUsageDescription\": \"...\"\n    }\n  }\n}\n\n# Build for TestFlight\nnpx eas build --platform ios --auto-submit\n```\n\n### Submit to App Store\n\n```bash\n# Via CLI (recommended)\nnpx eas submit --platform ios --latest\n\n# Or manually via App Store Connect\n1. App Store Connect\n2. Apps → Urban Helpers\n3. TestFlight → Builds\n4. Select build → Submit to App Review\n```\n\n**Review Time:** 24-48 hours\n\n---\n\n## 🔑 Code Signing\n\n### Android Signing\n\n```bash\n# Create keystore (one-time)\nkeytool -genkey -v \\n  -keystore urbanhelpers.keystore \\n  -keyalg RSA \\n  -keysize 2048 \\n  -validity 10000 \\n  -alias urbanhelpers\n\n# Backup keystore safely\ncp urbanhelpers.keystore ~/secure/urbanhelpers.keystore\n\n# Update eas.json\n{\n  \"build\": {\n    \"production\": {\n      \"android\": {\n        \"buildType\": \"apk\",\n        \"gradleCommand\": \":app:assembleRelease\"\n      }\n    }\n  }\n}\n```\n\n### iOS Signing (via Xcode)\n\n```bash\n# Automatic signing\n# Xcode → Project → Signing & Capabilities\n# Enable Automatic Signing\n# Select Team\n```\n\n---\n\n## 🔄 CI/CD Pipeline\n\n### GitHub Actions Workflow\n\n**Location:** `.github/workflows/build-apk.yml`\n\n**Triggers:**\n- Push to `main` branch\n- Manual dispatch\n- Tag creation (v*.*.* format)\n\n**Steps:**\n1. Checkout code\n2. Setup Node.js 20\n3. Setup Java 17\n4. Install dependencies\n5. Run TypeScript check\n6. Prebuild Android\n7. Build APK\n8. Upload artifact (14-day retention)\n\n**Artifact:** `UrbanHelpers-debug-apk`\n\n### Running Workflow Manually\n\n```bash\n# via GitHub CLI\ngh workflow run build-apk.yml -b main\n\n# or via GitHub UI\n1. Actions tab\n2. Workflows → Build APK\n3. Run workflow → Run\n```\n\n---\n\n## 📊 Version Management\n\n### Semantic Versioning\n\n```\nMAJOR.MINOR.PATCH\n1.0.0\n│ │ └─ Patch: Bug fixes\n│ └─── Minor: Features (backward compatible)\n└───── Major: Breaking changes\n```\n\n### Update Version\n\n**In `app.json`:**\n```json\n{\n  \"expo\": {\n    \"version\": \"1.0.0\",\n    \"android\": {\n      \"versionCode\": 1\n    }\n  }\n}\n```\n\n**In `package.json`:**\n```json\n{\n  \"version\": \"1.0.0\"\n}\n```\n\n**Commit:**\n```bash\ngit commit -m \"release: bump version to 1.0.0\"\ngit tag v1.0.0\ngit push origin main --tags\n```\n\n---\n\n## 📦 Release Process\n\n### Step 1: Prepare Release\n\n```bash\n# Update version in app.json & package.json\nnano app.json  # Change version to 1.1.0\n\n# Update changelog\necho \"## v1.1.0 - [Date]\n- Feature 1\n- Bug fix 1\" > CHANGELOG.md\n\n# Commit\ngit add -A\ngit commit -m \"release: prepare v1.1.0\"\n```\n\n### Step 2: Tag Release\n\n```bash\n# Create annotated tag\ngit tag -a v1.1.0 -m \"Release v1.1.0 - [Description]\"\n\n# Push tag\ngit push origin main --tags\n```\n\n### Step 3: Build & Deploy\n\n```bash\n# GitHub Actions automatically triggers\n# Monitor: Actions tab\n\n# Wait for build to complete (~10 minutes)\n```\n\n### Step 4: Create Release Notes\n\n```bash\n# On GitHub: Releases → Create Release\n# Select tag: v1.1.0\n# Title: Urban Helpers v1.1.0\n# Description:\n  ## What's New\n  - Feature 1 description\n  - Bug fix 1 description\n  \n  ## Download\n  - APK: [Link to artifact]\n  - Play Store: [Link]\n  - App Store: [Link]\n  \n  ## Installation\n  adb install UrbanHelpers-v1.1.0.apk\n```\n\n### Step 5: Publish to Stores\n\n```bash\n# Android (if not auto-submitted)\nnpx eas submit --platform android --latest\n\n# iOS (if not auto-submitted)\nnpx eas submit --platform ios --latest\n```\n\n---\n\n## 🧪 Pre-Release Testing\n\n### Internal Testing\n\n```bash\n# Build debug APK\nnpm start\n\n# Install on device\nadb install Troubleshooting\n\n### Build Fails\n\n```bash\n# Clear cache & rebuild\nrm -rf node_modules .expo\nnpm install --legacy-peer-deps\nnpx expo build:android --clear\n```\n\n### Signing Issues\n\n```bash\n# Regenerate signing config\nrm eas.json\nnpx eas build --platform android --interactive\n\n# Follow prompts to create new signing config\n```\n\n### Play Store Rejection\n\n**Common reasons:**\n- Crash on startup → Check error logs\n- Minimum API too low → Update to API 29+\n- Missing permissions → Declare in app.json\n- Privacy policy missing → Add URL\n\n**Fix:**\n1. Address rejection reason\n2. Bump version code\n3. Rebuild & resubmit\n\n### App Store Rejection\n\n**Common reasons:**\n- App crashes → Check TestFlight crash log\n- Missing privacy policy → Add URL\n- Data collection unclear → Be transparent\n\n**Fix:**\n1. Address rejection reason\n2. Bump build number\n3. Resubmit via App Store Connect\n\n---\n\n## 📈 Post-Release\n\n### Monitor\n\n- [ ] Check crash reports daily for 1 week\n- [ ] Respond to user reviews\n- [ ] Track daily active users\n- [ ] Monitor performance metrics\n\n### Iterate\n\n- [ ] Collect user feedback\n- [ ] Prioritize bug fixes\n- [ ] Plan next version features\n- [ ] Schedule next release (2-3 weeks)\n\n---\n\n## 🔒 Security Checklist\n\n- [ ] No hardcoded API keys\n- [ ] No debug logging in production\n- [ ] HTTPS enforced\n- [ ] Input validation on all forms\n- [ ] Rate limiting on API calls\n- [ ] Error messages don't expose internals\n- [ ] Sensitive data encrypted\n\n---\n\n## 📞 Support During Release\n\n### Deployment Day\n\n- Monitor GitHub Actions build\n- Check crash reports in real-time\n- Be available for critical fixes\n- Communicate status to team\n\n### If Issues Arise\n\n```bash\n# Hotfix critical bugs\ngit checkout -b hotfix/critical-issue\n\n# Fix & test locally\ngit commit -m \"fix: critical issue\"\n\n# Bump patch version\nnano app.json  # 1.0.0 → 1.0.1\n\n# Create release\ngit tag v1.0.1\ngit push origin main --tags\n```\n\n---\n\n## 📚 Additional Resources\n\n- [Expo Build Documentation](https://docs.expo.dev/build/introduction/)\n- [Google Play Console Help](https://support.google.com/googleplay/android-developer)\n- [App Store Connect Help](https://help.apple.com/app-store-connect/)\n- [React Native Security](https://reactnative.dev/docs/security)\n\n---\n\n**Happy deploying! 🚀**\n
